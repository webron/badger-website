Logging workouts

Logging sets, set types, and everything that happens on the training screen.

The training screen is where you spend most of your time in Badger. Pick an exercise, enter a weight and reps, and tap the check to log the set. The rest timer starts automatically after each working set.

Badger prefills each set from your last performance of the same exercise, so a typical set is one tap. If you started the workout from a routine, the plan's sets are laid out and waiting.

Warmup and working sets

Every set is either a warmup set or a working set. Warmups carry a W badge, do not count toward PRs or progress graphs, and are excluded from planned-vs-actual comparison.

  • Add warmup sets from the exercise menu; Badger generates a ramp from your working weight, snapped to plates you actually have.
  • Skip a set by long-pressing the check. Skipped sets stay in the plan but do not block finishing.
TipSet progress shows as tally marks next to each exercise. A full group of five gets its cross-stroke, just like the notebook you are replacing.

RPE, RIR, and set comments

Each set can optionally carry an RPE (1 to 10), an RIR (0 to 5), and a short comment for form cues or anything worth remembering next time.
